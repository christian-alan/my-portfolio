Hence this article is an effort to try out the ultimate promise and end the ancient discussion once and for all. Let us see how it goes!

In this article, I document my experience of building a custom drop-down menu shown in the video using Vue and Astro, with some code snippets to steal.

## The Component 

The purpose of the drop-down component is for the user to pick the person to who they intend to wire the money. The options are presented to the user in a chip-like format, where the chip anatomy of the chip is essentially the user's picture and their name wrapped in a thinly bordered container.

As the user clicks on the select field, a drop-down menu opens and the user is presented with all the possible options at their disposal by the system. Finally, the user is prompted to select one of the options and move on to the rest of the input fields.

## Technical Breakdown 

The component follows a simple notion of feeding a dataset to the component, processing the data through the component logic with the designed interaction, and eventually returning the result after the interaction.
